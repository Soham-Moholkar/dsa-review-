# Fixed sliding-window basics

Reuse work when a fixed-size substring moves one position.

Work through these in order:

1. [Substrings of Size Three with Distinct Characters](LeetCode/LC_1876_Good_Substrings_of_Size_Three/) — Easy; stable module ID 21
2. [Maximum Number of Vowels in a Substring of Given Length](LeetCode/LC_1456_Maximum_Vowels_in_Substring/) — Medium; stable module ID 22
3. [Minimum Recolors to Get K Consecutive Black Blocks](LeetCode/LC_2379_Minimum_Recolors/) — Easy; stable module ID 23
4. [Permutation in String](LeetCode/LC_567_Permutation_in_String/) — Medium; stable module ID 24
5. [Find All Anagrams in a String](LeetCode/LC_438_Find_All_Anagrams/) — Medium; stable module ID 25
6. [Count Occurrences of Anagrams](GeeksforGeeks/GFG_Count_Anagram_Occurrences/) — Medium; stable module ID 54
7. [Substrings of Length K with K-1 Distinct Characters](GeeksforGeeks/GFG_K_Length_K_Minus_One_Distinct/) — Medium; stable module ID 55
