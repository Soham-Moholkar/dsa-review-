# Fixed sliding-window basics

Work through these in order:

2. [Maximum Number of Vowels in a Substring of Given Length](LeetCode/LC_1456_Maximum_Vowels_in_Substring/) — Medium
3. [Minimum Recolors to Get K Consecutive Black Blocks](LeetCode/LC_2379_Minimum_Recolors/) — Easy
4. [Permutation in String](LeetCode/LC_567_Permutation_in_String/) — Medium
5. [Find All Anagrams in a String](LeetCode/LC_438_Find_All_Anagrams/) — Medium
