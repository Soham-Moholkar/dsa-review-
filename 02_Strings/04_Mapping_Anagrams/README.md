# Mappings and anagrams

Maintain one-to-one mappings and use canonical representations without losing multiplicity.

Work through these in order:

1. [Valid Anagram](GeeksforGeeks/GFG_Valid_Anagram/) — Easy; stable module ID 16
2. [Isomorphic Strings](GeeksforGeeks/GFG_Isomorphic_Strings/) — Easy; stable module ID 17
3. [Word Pattern](LeetCode/LC_290_Word_Pattern/) — Easy; stable module ID 18
4. [Group Anagrams](GeeksforGeeks/GFG_Group_Anagrams/) — Medium; stable module ID 19
5. [Determine if Two Strings Are Close](LeetCode/LC_1657_Close_Strings/) — Medium; stable module ID 20
6. [Uncommon Characters](GeeksforGeeks/GFG_Uncommon_Characters/) — Easy; stable module ID 52
7. [Make Anagram with Removals](GeeksforGeeks/GFG_Make_Anagram_with_Removals/) — Easy; stable module ID 53
