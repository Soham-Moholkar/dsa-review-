## What you are meant to learn

Use a rolling representation for repeated fixed-length substrings and reason about verification/collisions.

## Concepts required

- Rabin–Karp-style rolling hash
- fixed-length patterns
- collision awareness

## Prerequisites

- fixed windows
- hashing
- sets

## Attempt protocol

1. Read the live platform statement and constraints.
2. Add two of your own edge cases to `test_cases.txt`.

4. Record compiler errors, wrong assumptions, and failed cases in `mistakes.md`.
