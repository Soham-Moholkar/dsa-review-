Work through these in order:

1. [Find the Index of the First Occurrence in a String](LeetCode/LC_28_First_Occurrence/) — Easy; stable module ID 36

6. [Search Pattern (Rabin-Karp Algorithm)](GeeksforGeeks/GFG_Rabin_Karp_Search/) — Medium; stable module ID 60
