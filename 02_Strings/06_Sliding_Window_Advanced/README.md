# Variable sliding windows

Grow and shrink a window while maintaining a precise validity condition.

Work through these in order:

1. [Longest Substring Without Repeating Characters](GeeksforGeeks/GFG_Longest_Substring_Without_Repeating/) — Medium; stable module ID 26
2. [Longest Repeating Character Replacement](LeetCode/LC_424_Longest_Repeating_Character_Replacement/) — Medium; stable module ID 27
3. [Minimum Window Substring](GeeksforGeeks/GFG_Minimum_Window_Substring/) — Hard; stable module ID 28
4. [Number of Substrings Containing All Three Characters](LeetCode/LC_1358_Substrings_Containing_ABC/) — Medium; stable module ID 29
5. [Maximize the Confusion of an Exam](LeetCode/LC_2024_Maximize_Exam_Confusion/) — Medium; stable module ID 30
6. [Longest Substring with K Uniques](GeeksforGeeks/GFG_Longest_K_Unique_Substring/) — Medium; stable module ID 56
7. [Smallest Distinct Window](GeeksforGeeks/GFG_Smallest_Distinct_Window/) — Medium; stable module ID 57
