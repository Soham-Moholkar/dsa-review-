# Parsing and conversion

Translate representations, handle signs and overflow, and simulate arithmetic on strings.

Work through these in order:

1. [Roman to Integer](GeeksforGeeks/GFG_Roman_to_Integer/) — Easy; stable module ID 31
2. [String to Integer (atoi)](LeetCode/LC_8_String_to_Integer_Atoi/) — Medium; stable module ID 32
3. [Integer to Roman](GeeksforGeeks/GFG_Integer_to_Roman/) — Medium; stable module ID 33
4. [Add Strings](LeetCode/LC_415_Add_Strings/) — Easy; stable module ID 34
5. [Multiply Strings](LeetCode/LC_43_Multiply_Strings/) — Medium; stable module ID 35
6. [Add Binary Strings](GeeksforGeeks/GFG_Add_Binary_Strings/) — Easy; stable module ID 58
7. [Sum Numbers in a String](GeeksforGeeks/GFG_Sum_Numbers_in_String/) — Easy; stable module ID 59
