Work through these in order:

3. [Minimum Add to Make Parentheses Valid](LeetCode/LC_921_Minimum_Add_to_Make_Parentheses_Valid/) — Medium; stable module ID 12
4. [Evaluate Reverse Polish Notation](LeetCode/LC_150_Evaluate_Reverse_Polish_Notation/) — Medium; stable module ID 13
5. [Basic Calculator II](LeetCode/LC_227_Basic_Calculator_II/) — Medium; stable module ID 14
6. [Infix to Postfix](GeeksforGeeks/GFG_Infix_to_Postfix/) — Medium; stable module ID 58
7. [Minimum Bracket Reversals to Balance](GeeksforGeeks/GFG_Minimum_Bracket_Reversals/) — Medium; stable module ID 59
