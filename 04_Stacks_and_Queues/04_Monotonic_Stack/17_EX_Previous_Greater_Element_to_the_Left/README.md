## What you are meant to learn

Track the closest greater predecessor rather than a future element.

## Exercise contract

Return the nearest strictly greater VALUE to the left of each position, or -1.

## Concepts required

- decreasing monotonic stack
- left neighbor

## Prerequisites

- next greater
- iteration direction
