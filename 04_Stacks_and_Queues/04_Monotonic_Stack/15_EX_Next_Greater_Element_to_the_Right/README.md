## What you are meant to learn

Find the nearest strictly greater value to each element's right.

## Exercise contract

Return the nearest strictly greater VALUE to the right of each position, or -1.

## Concepts required

- decreasing monotonic stack
- right neighbor

## Prerequisites

- stack
- array indexes
