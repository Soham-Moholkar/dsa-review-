# Stack manipulation and recursion

Change a stack without forgetting what the call stack or auxiliary storage costs.

Work through these in order:

1. [Insert at the Bottom of a Stack](Exercises/EX_Insert_at_the_Bottom_of_a_Stack/) — Easy; stable module ID 6
2. [Reverse a Stack](GeeksforGeeks/GFG_Reverse_a_Stack/) — Easy; stable module ID 7
3. [Delete Middle Element of a Stack](GeeksforGeeks/GFG_Delete_Middle_Element_of_a_Stack/) — Medium; stable module ID 8
4. [Sort a Stack](GeeksforGeeks/GFG_Sort_a_Stack/) — Medium; stable module ID 9
5. [Validate Stack Operations](GeeksforGeeks/GFG_Stack_Permutations/) — Medium; stable module ID 57
