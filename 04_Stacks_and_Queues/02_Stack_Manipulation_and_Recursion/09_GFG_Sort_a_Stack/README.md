## What you are meant to learn

Decide how to preserve order while placing values in a stack, and count hidden recursion space.

## Exercise contract

Mutate the stack into nondecreasing order from bottom to top; rightmost is top.

## Concepts required

- recursion
- auxiliary stack
- ordering

## Prerequisites

- insert-at-bottom
- compare stack tops
