# Queue manipulation and circular queue

Reorder a FIFO and design circular or cross-adapter implementations.

Work through these in order:

1. [Reverse a Queue](GeeksforGeeks/GFG_Reverse_a_Queue/) — Easy; stable module ID 35
2. [Reverse First K Elements of a Queue](GeeksforGeeks/GFG_Reverse_First_K_Elements_of_a_Queue/) — Easy; stable module ID 36
3. [Interleave the First and Second Halves of a Queue](GeeksforGeeks/GFG_Interleave_the_First_and_Second_Halves_of_a_Queue/) — Medium; stable module ID 37
4. [Design Circular Queue](LeetCode/LC_622_Design_Circular_Queue/) — Medium; stable module ID 38
5. [Implement Queue using Stacks](GeeksforGeeks/GFG_Implement_Queue_using_Stacks/) — Easy; stable module ID 39
6. [Implement Stack using Queues](GeeksforGeeks/GFG_Implement_Stack_using_Queues/) — Easy; stable module ID 40
7. [Gas Station (Circular Tour)](GeeksforGeeks/GFG_Circular_Tour/) — Medium; stable module ID 64
