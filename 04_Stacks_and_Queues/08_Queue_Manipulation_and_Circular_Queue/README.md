# Queue manipulation and circular queue

Work through these in order:

35. [Reverse a Queue](GeeksforGeeks/GFG_Reverse_a_Queue/) — Easy
36. [Reverse First K Elements of a Queue](GeeksforGeeks/GFG_Reverse_First_K_Elements_of_a_Queue/) — Easy
37. [Interleave the First and Second Halves of a Queue](GeeksforGeeks/GFG_Interleave_the_First_and_Second_Halves_of_a_Queue/) — Medium
38. [Design Circular Queue](LeetCode/LC_622_Design_Circular_Queue/) — Medium
39. [Implement Queue using Stacks](GeeksforGeeks/GFG_Implement_Queue_using_Stacks/) — Easy
40. [Implement Stack using Queues](GeeksforGeeks/GFG_Implement_Stack_using_Queues/) — Easy
