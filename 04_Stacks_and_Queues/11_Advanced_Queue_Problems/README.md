# Advanced queue problems

Design flexible deques and practise level/state expansion without a graph syllabus.

Work through these in order:

1. [Design Circular Deque](LeetCode/LC_641_Design_Circular_Deque/) — Medium; stable module ID 51
2. [Design Front Middle Back Queue](LeetCode/LC_1670_Design_Front_Middle_Back_Queue/) — Medium; stable module ID 52
3. [Rotting Oranges](GeeksforGeeks/GFG_Rotting_Oranges/) — Medium; stable module ID 53
4. [Nearest Exit from Entrance in Maze](LeetCode/LC_1926_Nearest_Exit_from_Entrance_in_Maze/) — Medium; stable module ID 54
5. [As Far from Land as Possible](LeetCode/LC_1162_As_Far_from_Land_as_Possible/) — Medium; stable module ID 55
6. [Distance of Nearest Cell Having 1](GeeksforGeeks/GFG_Nearest_One_Distance/) — Medium; stable module ID 67
